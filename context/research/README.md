# context/research – materiał wejściowy projektu Trzy

Notatki z fazy odkrywania. To **materiał wejściowy**, a nie dokumenty bazowe kursu. Dokumenty bazowe (`prd.md`, `tech-stack`, `roadmap`, `test-plan`, `infrastructure.md`) powstają w `context/foundation/` przez skille kursu i mają pierwszeństwo.

| Plik | Do czego służy |
| --- | --- |
| `idea-brief.md` | zalążek dla `/10x-shape`: pomysł, użytkownik, przepływ, reguły biznesowe, model danych |
| `backlog.md` | historyjki US-001…, priorytety MVP / v1 / Później, sekcja NOT NOW |
| `audit-summary.md` | skrót niezależnego audytu: ryzyka, cięcie zakresu, kryteria GO / PIVOT / STOP |
| `decisions.md` | dziennik decyzji z uzasadnieniem i statusem |
| `forum-post.md` | post z projektem na forum kursu (dwie wersje) |

Stan na 2026-11-02. Część liczb (progi GO/STOP, ceny) to hipotezy do sprawdzenia, nie dane rynkowe.
